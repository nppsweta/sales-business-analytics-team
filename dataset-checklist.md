
# Dataset Preparation Checklist

## 1. Dataset Selection
- [ ] Identify a suitable sales dataset.
- [ ] Record the dataset source.
- [ ] Check whether the data can be used for this project.

## 2. Initial Inspection
- [ ] Identify the number of rows and columns.
- [ ] Review column names and data types.
- [ ] Check for missing values.
- [ ] Check for duplicate records.
- [ ] Identify inconsistent or invalid values.

## 3. Business Analysis Preparation
- [ ] Identify useful sales and revenue metrics.
- [ ] Decide which business questions to investigate.
- [ ] Identify fields needed for Power BI dashboards.

## 4. Team Coordination
- [ ] Assign dataset-related tasks.
- [ ] Record findings in the project repository.
- [ ] Discuss data quality issues with the team.
