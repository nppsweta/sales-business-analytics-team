
# Team Work Distribution

## Project
Sales & Business Performance Analytics

## Objective
Distribute project responsibilities fairly among four team members to complete the analysis, validate results, and prepare a Power BI dashboard and final report.

## Team Roles and Responsibilities

### Member 1 — Team Lead and Project Coordination
- Maintain the project plan and GitHub repository.
- Track daily progress and coordinate team activities.
- Review analysis results and resolve task dependencies.
- Perform final quality checks and consolidate the report.
- Coordinate branch reviews and merging into the main branch.

### Member 2 — SQL Analysis
- Write SQL queries to calculate key performance indicators.
- Analyze sales and profit by region, state, category, and sub-category.
- Calculate monthly and yearly sales trends.
- Validate query results and document findings.

### Member 3 — Python and Data Validation
- Use Python and Pandas to inspect and analyze the dataset.
- Verify data types, duplicate records, and data consistency.
- Calculate summary statistics and cross-check SQL results.
- Document validation results and analytical findings.

### Member 4 — Power BI Dashboard
- Import the cleaned dataset into Power BI.
- Create KPI cards for total sales, total profit, quantity, and profit margin.
- Build charts for regional, category, and time-based performance.
- Add suitable slicers and check dashboard accuracy.

## Shared Responsibilities
All members will:
- Commit meaningful work to their individual GitHub branches.
- Update progress and document completed tasks.
- Review findings and help resolve discrepancies.
- Participate in testing and final project review.
- Ensure that results are reproducible and supported by the dataset.

## Coordination and Dependencies
1. Confirm dataset quality before performing final analysis.
2. Use consistent KPI definitions across SQL, Python, and Power BI.
3. Compare calculated totals before finalizing dashboard visuals.
4. Review findings together before writing recommendations.
5. The team lead reviews contributions and coordinates merging into the main branch.

## Expected Deliverables
- SQL queries and analysis results.
- Python data validation and analysis documentation.
- Interactive Power BI dashboard.
- Business insights and actionable recommendations.
- Final project report and organized GitHub repository.

## Status
Task allocation documented. Individual assignments and progress will be updated as the project advances.
