
# Analysis Methodology

## Project
Sales & Business Performance Analytics

## Objective
Analyze the cleaned Superstore dataset to evaluate sales
performance, profitability, and business trends.

## 1. Dataset
The project uses Superstore_Cleaned.csv.

The dataset contains 9,994 records and the following fields:
- Order Date
- Region
- State
- Category
- Sub-Category
- Segment
- Sales
- Profit
- Quantity

## 2. SQL Analysis
SQL will be used to:
- Calculate total sales, total profit, and total quantity.
- Compare sales and profit across regions.
- Analyze category and sub-category performance.
- Compare customer segments.
- Examine monthly and yearly sales trends.

## 3. Python and Pandas Analysis
Python and Pandas will be used to:
- Load and inspect the cleaned dataset.
- Calculate key performance indicators.
- Group and summarize sales and profit data.
- Analyze trends and identify patterns.
- Validate key results against SQL calculations.

## 4. Power BI Visualization
Power BI will be used to:
- Display key performance indicators.
- Compare regional and category performance.
- Visualize monthly and yearly sales trends.
- Highlight low-profit and loss-making sub-categories.
- Add appropriate filters and interactive visuals.

## 5. Validation
The team will compare key totals calculated in SQL,
Python, and Power BI to identify discrepancies.

Any differences will be investigated and documented
before finalizing the dashboard.

## 6. Expected Deliverables
- SQL query files
- Python analysis files or notebooks
- Interactive Power BI dashboard
- Business insights and recommendations
- Final project report

## Status
Analysis methodology documented. Detailed analysis and
visualization work will be recorded as it is completed.
